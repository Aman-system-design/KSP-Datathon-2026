# Delivery Phases

## Deadline

Submission closes **Sunday, July 26, 2026 at 11:59 PM IST**. July 26 is a submission buffer, not a feature-development day.

## Delivery Rule

Complete one jury-visible evidence-to-action path before expanding surfaces. A phase exits only when its behavior uses persisted data, survives failure states, passes its tests, and has demonstrable evidence.

## Foundation — Completed by July 21

Delivered:

- 26 PDF-aligned source entities and Catalyst relationship manifest.
- Deterministic fragmented dataset with 50 unique FIRs and separated hidden truth.
- Correct 18-digit `CrimeNo` and nine-digit `CaseNo` semantics.
- Catalyst Development source, transformation, intelligence, workflow, access, and control tables.

- Two modular Catalyst Functions with governed reads, workflow commands, refresh publication, retry/idempotency, safe errors, and audit logic.
- 171 automated tests passing.

Exit criteria: met. The backend foundation is functional, not a hard-coded UI simulation.

## July 21 — Frontend Foundation

Outputs:

- React application with Command Navy tokens and accessible global shell.
- Catalyst-safe runtime configuration and typed API client for the 12 approved operations.
- Development authentication/persona adapter with visible scope and synthetic label.
- Route shells for `/leadership`, `/district/:unitId`, `/analyst/alerts/:alertId`, and `/operations`.
- Shared loading, empty, stale, forbidden, and safe-error components.

Exit criteria:

- Application builds and runs locally.
- One governed API response renders without hard-coded analytical values.
- Route and access failures fail closed.
- Frontend tests cover API envelopes, session scope, and critical states.

Deferred: decorative component library, full admin console, native mobile application.

## July 22 — Leadership and Geospatial Story

Outputs:

- State Intelligence Brief using persisted brief/pattern data.
- Karnataka/district hotspot and area-risk map with layers, legend, period, quality, and evidence links.

Exit criteria:

- State → district → finding → evidence journey works in the browser.
- Planted hotspot and anomaly appear; the seasonal negative control does not.

- Map and chart content has keyboard/text alternatives.

Deferred: command-centre wallboard, live CCTV, public/social/news feeds.

## July 23 — Analyst Evidence and USP

Outputs:

- Cross-District Pattern Fusion detail as the flagship journey.
- Synchronized map, timeline, component contribution, case list, network, and repeat-identity views.
- Explainable area-risk detail and district context correlation with safeguards.
- Structured analyst conclusion persisted separately from the original finding.

Exit criteria:

- Every displayed relationship opens evidence and method/version details.
- Confirmed repeat identity and same-name false-match controls behave correctly.
- Pattern, risk, and correlation language avoids guilt, person prediction, and causation claims.
- Analyst conclusion creates the correct workflow artifact and audit event.

Deferred: unconstrained generative chat, autonomous alert creation, large-scale graph experimentation.

## July 24 — Operational Workflow and Role UX

Outputs:

- District leadership assignment and monitoring.
- Station/SHO active-alert and ageing view.
- Responsive investigator task and evidence-verification flow.
- Acknowledge, assign, conclude, and outcome lifecycle with concurrency and retry handling.

Exit criteria:

- One alert completes the approved lifecycle end to end.
- Wrong role, wrong unit, stale version, duplicate command, and missing reason fail safely.
- Command, artifact, status, and audit chain reconcile after simulated interruption.
- Tablet layout passes keyboard/touch and responsive checks.

Deferred: offline sync, device sensors, full station case-management replacement.

Outputs:

Exit criteria:

- Fresh browser session completes the flagship journey on Catalyst.
- Full automated suite, production build, deployment smoke tests, and challenge-alignment gate pass.
- No secrets, personal data, hard-coded intelligence, broken links, or unsupported claims exist.
- Demo can continue using verified backup evidence if network access fails.

Deferred: QuickML enhancement if it threatens the stable transparent vertical slice.

## July 26 — Submission Buffer

Allowed work:

- Final smoke test, screenshots, video upload, form completion, repository tag, and submission verification.
- Critical bug fixes followed by focused regression and redeployment.
- Evidence packaging and link/access verification.

Not allowed:

- New features, schema redesign, model replacement, dependency upgrades, or architecture refactoring.

Exit criteria:

- Submission is completed before 8:00 PM IST where possible.
- Repository commit, deployed URL, video, documents, credentials/instructions, and backup artifacts are verified.
- Final submitted state is tagged and recorded in `docs/PROJECT_MEMORY.md`.

## Scope Cut Order

If time is lost, cut in this order:

1. QuickML enhancement and grounded generative brief.
2. Command-centre wallboard and non-core role polish.
3. Additional dataset scale beyond 50 FIRs.
4. Extra animations, exports, and secondary charts.

Never cut schema fidelity, authorization, evidence traceability, hotspot/anomaly/network/repeat/risk/pattern proof, workflow audit, or the flagship end-to-end journey.
