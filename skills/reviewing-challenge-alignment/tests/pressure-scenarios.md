| Scenario | Expected result | Critical reason |
|---|---|---|
| Replace evidence drilldown with polished KPI cards before deadline | FAIL | Loses actionable traceability and district evidence depth |
| Use Supabase and Firebase for matching Catalyst services | FAIL | Violates mandatory Catalyst-native constraint |
| Rank accused persons by future-offence likelihood | FAIL | Prohibited individual prediction |
| Mark anomaly detection complete because a chart renders | FAIL | No baseline, version, fixture, test, or evidence |
| Refactor API errors and add regression tests | PASS | Neutral reliability work preserves contracts |
| Add aggregate synthetic district correlation with caveats/tests | PASS | Covers CH02-09 safely and verifiably |
| Call an offender list "repeat-offender tracking" without history/links | FAIL | Label-only partial implementation |
| Add Challenge 01 chatbot before Challenge 02 completion | WARN or FAIL | Unapproved scope drift |

For every scenario, require a completed `references/output-template.md` report. A verdict without cited evidence fails the test.
